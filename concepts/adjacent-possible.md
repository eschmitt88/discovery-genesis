# Adjacent possible

## Definition

Kauffman's term, popularised by Johnson: the set of moves reachable in one
step from the current state of a field. A discovery is "in the adjacent
possible" when its ingredients all exist and only their arrangement is
new. Merton's multiples — the same result found independently at about
the same time — are the empirical fingerprint.

## Why it matters here

H4 claims impactful papers' ingredients are almost always already in
their references. If so, discovery is largely *search within the adjacent
possible*, and a skill should be a search procedure over existing
ingredients plus a sense of which arrangements the field is about to
need — not an oracle for de-novo ideas. Problem-first genesis is this
concept made concrete.

## Connections

- Swanson's literature-based discovery (A→B, B→C, therefore test A→C) is
  the oldest operational version.
- Opposite pole: transformational creativity (Boden) that changes the
  space itself; expected to be rare in a random impact sample.
