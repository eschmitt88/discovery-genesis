## Reasoning
Q_means is unambiguous and directly stated: the paper's own framing is "we report the first mode-locked laser based on a nonlinear monolithic high-Q factor resonator," explicitly crediting a new device architecture (and a newly coined mechanism name) as the reason stable, ultrahigh-repetition-rate, narrow-linewidth operation was achieved — the paper's logic runs capability → observation → claim exactly as the means-first template specifies. Q_problem required real weighing: the stability problem in fibre-cavity dissipative-FWM schemes is old, specific, and explicitly named ("their stability still remains a severe issue — a common problem"), which is the strongest pull toward problem-first in this card. But the problem-first test requires the closing ingredient to be pre-existing, and here it is explicitly new (introduced in this paper), which is the same "old problem, new capability" configuration that resolves to means-first elsewhere in this batch (cf. W2019385975). Q_idea is "no" — there is no proposition, only a device demonstration. Q_accretion is "no."

## Alternative reading
Problem-first is the genuine alternative and the closest competitor in this card — a coder weighting the age and specificity of the named stability problem over the age of the solving ingredient could defend it. I resolved toward means-first because the v1.1 rule's own worked distinction ("the capability is introduced in this paper... → means-first") points directly at this configuration, and because the paper's rhetorical center of gravity is unmistakably the device itself ("first... based on," "the key point is that this resonator...") rather than the problem it solves.
