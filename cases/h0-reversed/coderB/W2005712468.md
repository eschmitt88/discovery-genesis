## Reasoning
Q_problem is the clear "yes," directly quoted: "it is unknown why sea turtles ingest plastic," with an existing but incomplete hypothesis named and attributed to prior work. Q_means is "no" because the paper's own language flags the resource selection function as "traditionally used for habitat and food selection" — an established technique from an adjacent ecological application, imported rather than newly developed. Q_idea is "no": the prey-resemblance hypothesis under test is explicitly the literature's, not a proposition the authors stake out as new; the paper's own framing is to test and extend it with data, not to assert it as a starting premise. Q_accretion is "no" — this is a bounded field/statistical study. One clean "yes" leaves the reversed order nothing to arbitrate.

## Alternative reading
Idea-first is the closest alternative if one credits the authors with originating the refined hypothesis actually tested — not just "resembles jellyfish" but "debris selectivity varies systematically by turtle size class/feeding mode and specific debris properties (softness, clarity, color)." That refined framing is plausibly the authors' own synthesis. I did not code it idea-first because the text presents this refinement as emerging from the RSF modeling results ("Benthic phase turtles had a strong selectivity for soft, clear plastic, lending support to the hypothesis...") rather than as a premise stated before the analysis.
