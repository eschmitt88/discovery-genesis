## Reasoning
Q_means is the clear driver: the abstract explicitly credits a newly derived design model as the mechanism that produced the record result, matching the means-first capability→observation→claim template precisely. Q_problem reaches only "partial": MCF crosstalk is an old, actively studied problem (the reference list includes dedicated crosstalk-statistics papers from 2010-2011), but the specific ingredient that resolves it here — the new approximation model — is introduced in this paper, not pre-existing, which is the same "old problem, new theoretical capability" pattern seen elsewhere in this batch (W1989920209, W2019385975, W2040371569). Q_idea is "no" (a design-and-fabrication report, no proposition), Q_accretion is "no" (single fabrication/measurement study).

## Alternative reading
Problem-first remains the standing alternative on the same grounds as the batch's other "old problem, new theory" cases — a coder weighting the age/specificity of the crosstalk problem over the newness of the solving model could reasonably code this problem-first instead.
