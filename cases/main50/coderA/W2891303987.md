## Reasoning
This is a retrospective description of an already-established off-label clinical practice (using an old drug and route for a new symptom indication) rather than a new intervention, matching problem-first / gap-filling:first-measurement: the specific quantity being measured for the first time is the outcome/safety profile of intranasal fentanyl for this indication in this population, using a routine chart-review method. Confidence is high given the full text's explicit descriptive framing.

## Alternative reading
`is_primary: partial` could be argued if this is read as closer to a case-series/audit report than to hypothesis-driven primary research, but the paper reports original patient-level outcome data collected and analysed by the authors (not merely an artefact/tool), so I coded it `yes`.

## Notes for the codebook
Retrospective chart-review case series describing outcomes of an existing off-label practice are a distinct sub-genre from both case reports (single patient) and RCTs — the "first systematic description of an already-occurring practice" pattern maps cleanly onto gap-filling:first-measurement, but a codebook note distinguishing it from the case-report genre (see W2473872168) could help other coders align.
