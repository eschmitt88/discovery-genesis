## Reasoning
The abstract's own logical structure is capability-first: it names the data-scarcity problem, then presents a specific new technical capability (automated R-CNN-based dataset construction) as what made the subsequent result possible, matching codebook §1.2 means-first exactly. `instrument` is the central label for the enabling R-CNN pipeline; `gap-filling:next-target` is kept as a second label because "AI matches/exceeds dermatologists" is itself an already-established comparison paradigm (prior work on melanoma and other conditions is cited), and onychomycosis is the next disease target for that paradigm — removing this would lose that half of the genesis story.

## Alternative reading
problem-first is plausible if the R-CNN-based auto-annotation approach is itself already an established technique in the broader computer-vision field (not new to these authors or to dermatology specifically) — in that reading this would be a straightforward gap-filling:next-target case (established AI-vs-dermatologist paradigm, established auto-annotation techniques, applied to a new disease). I lean means-first because the abstract frames the data-generation method as the specific technical contribution that unlocked this result, not an incidental detail.

## Notes for the codebook
Useful test case for the means-first vs gap-filling:next-target boundary when a paper explicitly narrates a capability-first origin story for what is also a "next target in an active comparison paradigm" (AI vs. clinician) — both readings have real support, and I resolved via the abstract's own explicit problem->capability->result ordering per decision-order priority.
