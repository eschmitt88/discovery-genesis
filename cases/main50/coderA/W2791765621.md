## Reasoning
The full text explicitly contrasts its genome-scale, multi-marker approach with the field's prior reliance on 16S rRNA and a handful of housekeeping genes — a clearly stated, established gap. The core methodology (phylogenomics combined with conserved signature indels and proteins, CSI/CSP) is a recognizable comparative-genomics approach that this research group has applied to numerous other bacterial genera in prior work (a pattern strongly suggested by the systematic, formulaic nature of the CSI/CSP method itself, which functions as a general-purpose bacterial-taxonomy tool rather than something built specifically for Mycobacterium). This is the "established platform applied to the next genus" pattern the frozen v1.1 rule names directly: problem-first, gap-filling:next-target.

## Alternative reading
Means-first would apply if the specific set of 150 Mycobacterium genomes, only recently available at genome-scale, constituted the enabling new capability (a new-dataset-or-resource) that made this analysis possible for the first time, with the CSI/CSP method being secondary. I weighted the reused-methodology reading more heavily given how the introduction frames the contribution as methodological rigor (genome-scale, independent molecular signatures) rather than data availability, but this is a genuinely close call.

## Notes for the codebook
Comparative-genomics taxonomic-revision papers using an established signature-based pipeline (CSI/CSP or similar) across many genera are a recurring, easily-identifiable "own platform on next target" pattern — worth a named example, since the tell here (a formulaic, clearly reusable analytical pipeline) is method-shaped rather than citation-count-shaped, a variant of the frozen rule's tell worth naming explicitly.
