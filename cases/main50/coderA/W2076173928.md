## Reasoning
The abstract states the problem plainly (both existing indicators are known to misrepresent glycaemic control in this population, citing the authors' own 2011 prior finding) and the fix is a regression-derived adjustment built from two already-existing assays (glycated albumin, serum albumin) — not a new instrument or measurement technology. That is problem-first. Within move labels, "We found for the first time" plus the specific-population framing fits `gap-filling:first-measurement` best (a corrected indicator tested for the first time in this system), rather than `next-target` since the target population is the same one the authors had already flagged as a gap in 2011.

## Alternative reading
Means-first would apply if the regression/adjustment procedure itself were being introduced as a generalizable new method rather than a population-specific fix — the abstract's narrow framing ("in these patients") argues against that reading.

## Notes for the codebook
This is a borderline `first-measurement` vs `next-target` case: the authors' own prior paper (2011) already named the population as understudied, so the "new target" was arguably opened by that earlier paper, not this one — this paper's contribution is the specific corrected metric (a first-measurement move) rather than simply visiting a new target. Worth a worked example distinguishing "paper that opens a target" vs "paper that answers the question in a target already opened by the same group."
