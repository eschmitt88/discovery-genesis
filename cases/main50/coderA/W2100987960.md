## Reasoning
This is a clean instance of the v1.1 tell for problem-first: the same CBD + SPST combination recurs across this group's own cited prior work (1982, 1993, 2003, 2010), so the capability is not new to the authors even though it's being pointed at a more narrowly defined population (treatment-naïve, not previously medicated) than the 2010 "preliminary report." Evidence that would change my mind: if full text showed a genuinely new CBD delivery method or a new physiological measure not used in the 2010 precedent.

## Alternative reading
Means-first is tempting because CBD is a specific pharmacological agent, but the rule is explicit that reapplying an established agent/paradigm to the next patient subgroup is problem-first, not means-first — the "capability" (CBD + SPST) predates this paper by decades in the same authors' hands.

## Notes for the codebook
Good worked example for the "serial reuse of own platform, next population" rule — the citation trail (own prior papers, same drug + same behavioral paradigm) is unusually explicit here.
