## Reasoning
None of the individual nonlinear features or classifiers are new; each has an established pedigree in a different biomedical-signal application (epilepsy, gait, Alzheimer's MEG). The paper's central move is combining several such features from within the same broad EEG/biomedical-signal-processing field with standard ML classifiers — recombination within a field, not transfer across a field boundary, per the codebook's boundary rule. Evidence that would change my mind: if one feature (e.g., correlation dimension) had never before been applied to EEG at all, which would push toward gap-filling:next-target instead.

## Alternative reading
gap-filling:next-target is a plausible second reading (established nonlinear-EEG toolkit applied to a new diagnostic target, depression) but the abstract's own framing centers on the value of combining multiple features, which is a recombination move rather than a single-method transplant.

## Notes for the codebook
Feature-engineering/ML-classification papers that stitch together several established signal-processing techniques for a new clinical target are a recurring recombination-vs-next-target ambiguity; the decisive signal I used was whether the paper's own selling point is "combination beats any single feature" (recombination) vs. "we're the first to apply X here" (next-target).
