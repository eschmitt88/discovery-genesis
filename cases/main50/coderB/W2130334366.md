## Reasoning
This is a standard applied-agronomy field trial: an established soil-metal test (DTPA, 1978) and dose-response design (used across a large existing sewage-sludge/heavy-metal literature from 1998-2011) applied to a specific site/climate/outcome combination (semiarid subirrigated pasture, Turkey, metal content) not previously reported — and a 2011 reference on the same Turkish semiarid pasture system (different outcome variables) suggests this is the same group's platform reused. Rule-3 problem-first, `gap-filling:next-target` as the move.

## Alternative reading
`idea-first` is a weak alternative if the paper is read as testing a specific stated hypothesis (e.g., a dose threshold below which metal uptake stays low) rather than an open-ended dose-response survey. Judged less likely because the abstract describes a standard multi-dose field trial with metal content as one of several measured outcomes, not a single proposition-driven design.
