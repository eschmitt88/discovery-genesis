## Reasoning
This is a clean instance of the v1.1 problem-first tell: an established method (pattern perturbation for MMC, introduced in the authors' own 2007 paper, itself building on MMC applications to optical communications from 2003) is applied to a new target (WDM systems) rather than a new capability being introduced. The abstract's own verb — "extended" — states the move directly, and no new instrument, dataset, or theoretical apparatus appears; only the state space being sampled changes (single-channel bit pattern → multi-channel bit pattern).

## Alternative reading
`means-first` would apply only if extending to WDM required a genuinely new sampling/algorithmic capability not present in the single-channel method. Judged unlikely because the abstract frames the WDM case as a direct extension using the same perturbation mechanism, with the only stated novelty being the applicability to the larger multi-channel state space.
