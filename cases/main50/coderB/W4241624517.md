## Reasoning
This is a means-first case under v1.1: the new capability (a design model that newly incorporates bend into the crosstalk relation, plus the trench-assisted core structure) is introduced within this paper rather than reused from the authors' own prior work — the cited prior MCF papers (2009, 2010) are competing/superseded designs, not a platform this group is applying serially to a new target. The paper's logic explicitly runs new-model → design → fabrication → record measurement, matching the means-first definition directly.

## Alternative reading
`gap-filling:next-target` is a weaker alternative if this is read as "yet another multi-core fiber design in an active field," but the abstract's explicit claim of a *new* approximation model (not reuse of the 2009/2010 statistical crosstalk model) and the record-setting, first-of-its-kind numeric result argue against treating this as routine serial iteration.

## Notes for the codebook
Fabricated-device engineering papers that both derive new theory and report a record physical result are a recurring means-first pattern (cf. the antenna paper W2027918153, which was closer to idea-first because no new theory/capability was introduced there) — useful contrast pair for a means-first vs idea-first worked example in engineering domains.
