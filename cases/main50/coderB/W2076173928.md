## Reasoning
The abstract names a specific, already-established clinical problem (two established indicators both fail, for known and different reasons, in this specific patient subgroup) and closes it with an existing statistical technique (linear regression/adjustment) rather than a new instrument — placing this under problem-first. The paper's central contribution is a new, formally specified adjusted quantity computed via regression, which independently satisfies `formalisation` (an informal notion — "correct GA for albumin's confounding effect" — given a computable representation, the regression-derived adjusted-GA formula); removing that label would drop a real part of the contribution, so it is kept as a second label alongside `gap-filling:first-measurement` (the first empirical test of this adjusted indicator's accuracy in this population).

## Alternative reading
Means-first is a weaker alternative: if the regression-adjustment technique itself were novel to nephrology/diabetology, this would be means-first. It is not — regression-based bias correction is routine statistical practice; only its specific application here is new, consistent with problem-first.

## Notes for the codebook
This is a useful boundary case for `formalisation` vs `gap-filling:first-measurement` co-listing: a paper that both proposes a new computable indicator and is the first to test it. The codebook could clarify whether "propose + first-test a new derived metric" defaults to listing both or to picking whichever is more central.
