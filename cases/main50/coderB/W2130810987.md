## Reasoning
Every individual method (ploidy/SSI scoring, CGH, microarray differential expression) is cited to established prior technique, and the proteomic layer is explicitly reused from the authors' own earlier publication on the same sample set — this is the v1.1 pattern of an established platform (here, multiple established profiling modalities plus a reused prior dataset) applied to answer a next specific question, which is problem-first. The central move is recombination: joining genome (CGH), transcriptome (microarray) and proteome (prior work) layers on one sample set to test a specific correlational hypothesis about instability vs. histology — not a new instrument, and not crossing a field boundary (all firmly within cancer genomics/molecular pathology). Evidence that would change my mind: if the CGH or microarray protocol itself had been newly developed for this paper rather than cited to established technique.

## Alternative reading
gap-filling:first-measurement is a plausible secondary reading (first time these three data layers are jointly correlated with instability grade specifically in endometrial cancer), but I did not add it as a second label since recombination alone makes the card true — dropping it would not misrepresent the paper's central move, which is the multi-layer integration itself rather than any single new measurement.

## Notes for the codebook
Multi-omics integration papers (genome+transcriptome+proteome on one sample set, with one layer explicitly imported from the authors' own prior publication) are a recurring cancer-biology pattern worth naming: each individual assay is established and often cited to the authors' own earlier work on the very same samples, which makes the "capability new to the authors" test unusually clean to apply — the explicit "reported earlier [ref]" phrasing is a strong textual signal.
