## Reasoning
The automated CT segmentation/localization algorithm is explicitly described as "previously developed" and is supported by a run of the same group's own prior methods papers in the reference list (2011–2018) — the clearest possible instance of the v1.1 tell (a method cited repeatedly in the authors' own prior work signals problem-first, not means-first). The explicit motivation ("findings regarding the effect of insertion depth have been inconsistent") plus the larger sample size (220 ears vs. smaller prior cohorts) makes `gap-filling:bigger-n` the precise sub-label: same question, same established method, larger sample to resolve disagreement in the literature.

## Alternative reading
`gap-filling:first-measurement` was considered for the array-type-stratified analysis (precurved vs. straight arrays analyzed separately), which is a genuinely finer-grained result than most prior studies report. This was not made primary because the abstract's own framing ("further evidence... our results confirm the significance...") centers on resolving an existing inconsistency with more data, which is squarely bigger-n.
