## Reasoning
With 401 references spanning 1961–2013 and an abstract explicitly announcing itself as a review presenting existing remediation knowledge, this is a clear accretion case — the "mobilize vs. immobilize" organizing dichotomy is a synthesis lens applied to an existing body of soil-chemistry findings, not a new empirical result. `Consolidation` is the appropriate single move label.

## Alternative reading
`Formalisation` was considered, since organizing many disparate remediation techniques under one binary conceptual framework has a mild formalizing flavor. It was set aside because the mobilize/immobilize distinction is a standard, already-informal organizing concept in this literature (not given a new formal/computable representation here — no equation, ontology, or metric is introduced), so it does not meet the codebook's formalisation bar.
