## Reasoning
Both ingredients — the directed-forgetting paradigm and salivary hormone assays paired with cognitive tasks — are individually established, and their combination is itself already a recognizable sub-literature in this reference list (hormones + specific memory tasks recur from 2002 onward). This is best read as extending an established combined methodology to a specific paradigm/subject-group combination not previously tested (list-method directed forgetting across naturally cycling, OC, postmenopausal, and male groups simultaneously), which is `gap-filling:next-target` under problem-first: no new capability is introduced, only a new application of existing tools to a more specific question.

## Alternative reading
`Recombination` was considered (joining a cognitive-control paradigm with endocrinology), but per the codebook's same-field rule this pairing is already routine within cognitive neuroscience/psychoneuroendocrinology (many cited refs already combine hormone measures with memory tasks), so it reads as extending an established joint methodology to a new specific task rather than a novel cross-field join.
