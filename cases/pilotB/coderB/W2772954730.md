## Reasoning
My first instinct, noticing that the ELISA biomarker methodology is cited back to the authors' own prior sports-immunology papers (futsal and handball players), was to read this as another means-first "established assay pointed at a new context" case like the RIG-I and p73 papers earlier in this batch. On reflection I judged that pattern too weak here to override the paper's own explicit framing: only two prior self-citations (not the four-to-eight-paper "marker mill" pattern seen elsewhere), and the introduction's own emphasis falls squarely on the previously-untested combination (exergaming + these specific markers), stated directly as a novelty claim. That is the problem-first signature in codebook §1: a named open question, closed with a pre-existing (if familiar-to-the-authors) ingredient.

## Alternative reading
Means-first remains plausible: the authors' own validated cytokine/adipokine panel, ready to be pointed at any new exercise modality, could be read as the generative capability, with exergaming simply the next convenient population/intervention to run it on. I rate this second because the introduction foregrounds the specific unstudied combination rather than the assay's availability.

## Notes for the codebook
Placed alongside W2891229446 (RIG-I) and W2044126692 (p73) in this batch, this card is a useful negative control for the "established-assay-reused" heuristic: not every paper that cites the authors' own prior methodology as precedent should default to means-first — the number of prior applications and the paper's own framing both matter, and I initially over-applied the pattern here before reconsidering.
