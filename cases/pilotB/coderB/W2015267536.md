## Reasoning
This paper is genuinely hard to place. The dominant activity — pulling six months of routine hospital biochemistry records and checking practice against a guideline — reads as means-first: the capability (a retrospective data pull that was already sitting in hospital records) is why this analysis exists, and the paper's several sub-findings (compliance audit, age-mortality, jaundice-mortality) look like things noticed within an available dataset rather than questions posed in advance and then answered. The `routine-data-wave` enabler term fits precisely. I did not choose accretion because there is a genuine, non-predetermined empirical claim (jaundice associated with survival) whose direction was not knowable in advance — that rules out the "only the numbers were blank" test.

## Alternative reading
Problem-first is a real alternative: the text does frame "it is not clear if development of jaundice has any prognostic value" as a standing open question before presenting the data, and one could read the routine data as merely the (pre-existing) ingredient used to close that question. I rate this second because the paper's own methods section foregrounds the data pull and guideline audit as the primary design, with the jaundice finding read more like a byproduct highlighted in Discussion.
