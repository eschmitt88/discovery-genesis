## Reasoning
The paper names an open question (RIG-I in gastric cancer, unexplored) but its methods reveal a serial-marker-study pattern: the same tissue array and IHC/knockdown pipeline recur verbatim across the authors' own prior papers on unrelated genes (B7-H3, B7-H4, PD-L1, IFIT2), all cited as methodological precedent from the same group. That pattern — an established assay platform being run on the next candidate gene — is the means-first signature codebook §1 describes (capability → observation → claim), and per the decision order means-first is checked before problem-first, so it takes priority here even though a gap statement is also present.

## Alternative reading
Problem-first is a reasonable alternative reading: RIG-I's established role in other cancers is a genuine, field-recognized open question when gastric cancer specifically is unstudied, and one could read the tissue array as simply the pre-existing ingredient used to close it. I rate this second because the methodological self-citation pattern (four near-identical prior papers on the same platform) suggests the resource, not the specific hypothesis about RIG-I, is doing the work of selecting what gets studied next.

## Notes for the codebook
This is a useful example for calibrating means-first vs. problem-first when a lab runs a repeatable assay platform serially across many candidate genes: the "gap statement" (X unstudied in cancer type Y) can co-occur with a means-first genesis when the same platform has already been used to close an analogous gap for genes X-1, X-2, X-3. The decision order (means-first before problem-first) resolves this cleanly but it is worth flagging as a recurring pattern likely to recur at larger n.
