## Reasoning
The dossier gives no abstract or full text, only title and a 36-item reference list, so the case rests on inference. The reference list mixes an old, imported instrument (Cre-ERT2 lineage tracing, 1999, originally used in epidermis) and an existing transgenesis tool (I-SceI meganuclease, 2002) with a live but unresolved question in a specific model system (zebrafish heart regeneration since 2002, contested cell-of-origin through 2007-2009 mammalian fate-mapping debates). The title phrasing ("Primary contribution... by gata4+ cardiomyocytes") reads as an empirical result statement, not a hypothesis restated as a conclusion — consistent with means-first (the tracing tool revealed the answer) rather than idea-first (a stated proposition confirmed by design). Evidence that would change my mind: full text showing the authors explicitly predicted this result from prior mammalian p38-MAPK-inhibition literature before running the experiment, which would push toward idea-first.

## Alternative reading

I rate this less likely as the primary reading because the decisive contribution is the fate-mapping instrument itself settling a genuinely open, two-sided debate — the "idea" being tested wasn't novel, only its direct in vivo demonstration was.
