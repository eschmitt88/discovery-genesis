## Reasoning
Every individual ingredient (OpenIE, entity linking, semantic role labeling, RDF) is established prior work cited across a wide, multi-lab reference list (2003-2017), so this isn't `next-target` reuse of a single authors' own platform — it's a genuinely new combination the abstract itself flags as underexplored ("OpenIE approaches have been slightly explored for the construction of KGs"). That, plus the capability→result→claim structure of the abstract, makes this a clean means-first case with `recombination` as the central move: joining several existing NLP/Semantic-Web techniques within the same field into a new pipeline.

## Alternative reading
problem-first is a plausible second reading if one treats "how to build coherent KGs from unstructured text" as the long-standing open question and this paper's specific combination as simply the latest existing-tool answer — but the abstract's explicit novelty claim about the OpenIE+grammar integration itself (not just applying it to a new corpus or domain) tips this toward means-first rather than problem-first.
