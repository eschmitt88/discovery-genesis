## Reasoning
The dose-response bioassay methodology used here (cited to a 1995 log-logistic dose-response paper and a 2015 R package for dose-response analysis) is standard, general-purpose ecotoxicology methodology, not something built for this paper. What's new is the specific finding — resistance in this particular population, quantified for the first time — which is a clean `gap-filling:first-measurement` case and problem-first genesis: the field-report-driven concern (an existing, if recent, "problem") is closed using off-the-shelf assay methodology.

## Alternative reading
means-first would require treating the bioassay protocol itself as new or newly adapted for this species/context, but the abstract explicitly calls it "a widely implemented bioassay protocol," which argues against that reading. I don't see a strong case for it here.

## Notes for the codebook
Unambiguous case; no coding friction. Good example of `gap-filling:first-measurement` as distinct from `next-target` — this isn't extending a diagnostic method to a new species (as in W2899493151), it's measuring a specific effect (resistance level) in an already-studied system (D. suzukii, an established invasive pest since 2010) for the first time.
