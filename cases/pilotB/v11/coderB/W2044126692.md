## Reasoning
This is a candidate-gene association study following a well-worn template (genotype a known polymorphism by PCR-RFLP, compare allele frequencies across case/control groups) that has already been run on the same polymorphism in numerous other cancers, and appears to be run repeatedly by the same Portuguese group on the same cervical-cancer cohort with different candidate genes each time (TP53 codon 72, TNF-α, CCR2-64I, cyclin D1 all appear in the reference list as cervical-cancer-specific prior work). That double pattern — same polymorphism reused across diseases, and same disease cohort reused across genes — is exactly the v1.1 "serial reuse of an established platform on a new target" signature, making this a clean problem-first case rather than means-first.

## Alternative reading
means-first would require the PCR-RFLP genotyping itself to be new or newly adapted here, but it is cited to 2004 prior work and used identically to how it's used for other cancer types — I see no capability-newness signal to support means-first.

## Notes for the codebook
Unambiguous application of the v1.1 next-target rule; strengthens the case that the "next-target" tell generalizes well beyond biomedicine's gene/species examples to the specific pattern of candidate-gene association studies, where it's especially common (same polymorphism panel run across many disease cohorts, or same cohort run across many candidate genes).
