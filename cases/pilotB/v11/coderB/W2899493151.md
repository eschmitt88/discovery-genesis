## Reasoning
The reference list contains an evident own-lab methodological lineage (2004 SYBR Green real-time PCR for Bactrocera latifrons, 2005 real-time qualitative PCR for other Bactrocera species, 2015 "real-time PCR toolbox for accurate identification of invasive fruit fly species") that reads as the same diagnostic pipeline being extended, species by species. That matches the v1.1 problem-first tell precisely: the assay-design method itself is not new to this paper; what's new is the target (these two specific, previously un-assayed species) and the operational trigger (repeated border interceptions).

## Alternative reading
means-first would apply if the specific primer/probe design or in silico specificity-testing approach were itself a methodological first for this group — the abstract doesn't distinguish routine application from genuine assay-design innovation, so full text could shift this reading. I weighted problem-first higher given the clear serial-reuse signature in the reference list.
