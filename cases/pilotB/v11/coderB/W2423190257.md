## Reasoning
No single ingredient here is new: Rb saturated-absorption references, comb generation via EOM-in-cavity, and SHG frequency transfer are all cited to work from the 1990s-2000s, several from the same University of Neuchâtel group (2005 "compact laser head for Rb atomic clocks"). The atmospheric-sensing reference cluster (2008-2017) signals the driving application, which is what is genuinely new about the question — a compact source at exactly 1.55/1.557 µm with the stability spaceborne IPDA lidar needs. That satisfies problem-first per codebook §1.3: ingredient not new, question is.

## Alternative reading
means-first is a live alternative if the specific combination (Rb-at-780nm + SHG + EOM comb, in one compact package) is itself the field's first working instance rather than a routine assembly — the abstract's phrasing ("Combining... techniques... is demonstrated") leans toward presenting the combination as the achievement. I coded problem-first because the application-need framing (lidar) dominates the abstract's opening sentence, but full text could tip this to means-first.

## Notes for the codebook
This case sits close to the boundary the v1.1 rule addresses (established techniques recombined to solve a stated application problem) — it's not "same authors, new target" in the biology sense, but structurally analogous: an established multi-part technique repurposed for a new spectral target driven by an external application need.
