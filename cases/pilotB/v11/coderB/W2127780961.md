## Reasoning
This is a large retrospective analysis of an already-running clinical screening program's data, undertaken specifically to answer a stated evidence gap (real-world performance/interval safety) that prior, smaller randomized trials had not resolved. Per codebook §1.3, the ingredient (the KPNC program and its accumulated outcomes data) need not be new — what's new is the specific question (interval safety in routine practice at this scale), which is a clean problem-first case. `gap-filling:bigger-n` fits precisely: the same underlying question (co-testing performance, interval safety) is answered with a far larger, longer, more representative sample than prior trial cohorts.

## Alternative reading
means-first is a weak alternative if one treats the very large linked clinical dataset itself as a "new resource" enabling the finding — but the program was not built for this study; it's routine clinical care data repurposed retrospectively, which the codebook's enabler vocabulary explicitly separates from means-first via `existing-resource-repurposed`.

## Notes for the codebook
Clean, high-confidence exemplar of `gap-filling:bigger-n` as distinct from `next-target`: this isn't a new population/species/material, it's the same population and question answered with a much larger and more representative (routine-practice vs. trial) sample.
