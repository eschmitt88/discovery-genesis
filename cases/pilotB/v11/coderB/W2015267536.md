## Reasoning
Full text confirms two explicitly stated gaps, both closed with existing ingredients: the guideline-compliance audit reuses Sherwood et al.'s (2001) primary-care audit design in a new clinical setting (`gap-filling:next-target` — new target = secondary/acute care rather than primary care), while the jaundice-survival question is answered for the first time using routinely collected biochemistry data already on file (`gap-filling:first-measurement`). No new instrument, assay, or dataset was built; both aims are named as open questions in the introduction before any data are presented, which is the clean problem-first signature.

## Alternative reading
means-first would require treating the retrospective identification/stratification method as a novel capability, but it's a routine chart-review audit design (used by Sherwood nine years earlier) — I see no capability-newness case for means-first here.

## Notes for the codebook
Kept both `gap-filling` sub-labels because the abstract itself states two co-equal aims (guideline audit in a new setting; a new mortality-prognosis question) and removing either would misrepresent the paper — a legitimate case for the "second label only if removing it would make the card false" bar, rather than a default pairing.
