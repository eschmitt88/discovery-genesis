## Reasoning
This is a secondary/exploratory analysis of an already-completed randomized trial, using the trial's existing mutation and outcome data to answer a question (does duration benefit vary by mutation subtype) the primary report did not address. The trial and its mutation dataset are the ingredient, already existing; the question is what's new — clean problem-first per the codebook's explicit note that the ingredient need not be recent. I coded gap-filling:first-measurement because the paper measures, for the first time, the duration-by-mutation-subtype interaction in this trial population.

## Alternative reading
means-first would require treating the "exploratory" statistical subgroup analysis itself as a new capability, but Bayesian/frequentist subgroup-interaction analysis on RCT data is a routine method, not a new instrument or assay — I don't think this reading survives contact with the v1.1 "capability new to the authors or field" bar.

## Notes for the codebook
Clean, unambiguous exemplar for the "existing completed trial repurposed for a new question" problem-first pattern the codebook already anticipates (§1.3). No real coding friction here.
