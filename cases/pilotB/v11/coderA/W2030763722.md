## Reasoning
The abstract's own causal chain is capability-first: an existing assay (MLPA, established since 2002) could not be run at the DNA quantities available from the target resource (DBSS), so a new probe design was built specifically to close that gap, and only then was the pilot detection study run. That is means-first by the codebook's definition even though the underlying assay class is old — the capability that "is the reason the finding exists" (the low-input redesign) is introduced in this paper. Evidence that would change my mind: full text showing the redesign was itself routine/incremental relative to prior low-input MLPA work already published by others (cited 2008, "MLPA Technique for Copy Number Analysis on Small Amounts of DNA") — which would weaken the means-first case toward problem-first (established low-input MLPA method applied to a new target, DBSS).

## Alternative reading
Problem-first is a real alternative: a 2008 reference already describes "MLPA... for Copy Number Analysis on Small Amounts of DNA," so the low-input approach may not be wholly new to the field, and this paper could instead be read as an established low-DNA MLPA method applied to a next target (dried blood spots specifically). Without full text I cannot tell whether this paper's design is a genuine advance over that 2008 method or a straightforward reapplication.

## Notes for the codebook
This is a good worked example for the "means-first requires capability new to authors OR field" clause: the paper's own abstract claims novelty, but a same-topic 2008 reference in its own list raises the question of field-level precedent, which abstract-only evidence cannot resolve.
