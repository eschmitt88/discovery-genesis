## Reasoning
The reference list shows the same combined CGH/expression/proteomic/SSI pipeline cited repeatedly across the authors' own prior work on breast (2004), colorectal (2006), and prostate cancer, which is the v1.1 tell for problem-first serial reuse of an established platform rather than means-first. The open question — does genomic instability, not just histology, drive expression change — was already answered analogously in other tumor types by this same group.

## Alternative reading
Means-first could apply if endometrial-specific application required a materially new instrument, but the methods section shows the same CGH/microarray/IPA workflow as their earlier papers, so problem-first is the better fit.

## Notes for the codebook
This is a clean instance of the "next-target" pattern the v1.1 rule was written for — same platform, new tissue type — and the SELF-citation marking made the call fast and confident even from a compact dossier.
