## Reasoning
The self-citation cluster (2006-2012) shows this paper as the latest step in the same lab's long-running characterization of the petunia/Antirrhinum anthocyanin MBW network, using established transformation and interaction-assay methods rather than any new capability — the v1.1 problem-first pattern. The specific open question (what represses the MBW activation complex, and how) was set up by the same authors' own prior identification of the activator components.

## Alternative reading
Idea-first is a weak alternative if the "reinforcement and feedback regulation" model is read as a novel proposition driving the design, but the abstract frames the work as characterizing an existing gene regulatory network empirically (identifying MYB27, mapping its targets) rather than testing a stated hypothesis, so problem-first fits better.

## Notes for the codebook
This is a "fill in the next node of a known network" pattern — the authors' own established system, extended to a new specific regulatory component — which is a slightly different flavor of next-target than species/population substitution; a worked example distinguishing "next gene in an established network" from "next species with an established method" could sharpen the codebook.
