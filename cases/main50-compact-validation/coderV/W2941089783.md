## Reasoning
The dense self-citation cluster and the paper's own "focus on methodology" framing point to problem-first serial extension of the authors' established Porto groundwater-mapping platform, rather than a new capability: every individual component (DRASTIC-family indices, AHP, GIS software) is decades old and none is newly introduced here. The genuinely new element is the formalised combination itself (the IPI-Urban weighted index), which is a recombination of existing techniques rather than a new instrument.

## Alternative reading
Means-first would apply if the geovisualisation/GIS coupling itself constituted a new capability for the authors, but their own prior self-citations (2013-2019) already use GIS mapping for urban groundwater assessment in the same city, so the coupling is better read as a refinement/formalisation of an existing platform.

## Notes for the codebook
This is a case where `is_primary: partial — methodology paper` and `move: formalisation` co-occur naturally — a paper proposing a new named index built entirely from established components. The codebook's framework/methodology categories could use a clearer worked example distinguishing "new index built from old parts" (recombination + formalisation) from a genuinely new measurement capability.
