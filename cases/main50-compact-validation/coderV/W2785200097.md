## Reasoning
The introduction states the study's explicit design logic: resolve the field-wide dataset-scarcity bottleneck for medical deep learning with a new capability (an R-CNN-based automated dataset-construction pipeline), then measure whether the resulting scale enables AI to match specialists — the textbook means-first capability-to-observation-to-claim shape, even though the individual CNN architectures (ResNet, VGG, Faster R-CNN) are all pre-existing, externally developed tools.

## Alternative reading
Gap-filling:next-target is a plausible alternative if one treats "apply deep learning to another skin/nail condition" as simply extending an established genre (dermatologist-level skin cancer classification, 2017) to onychomycosis, but the paper's own framing credits the automated-dataset-construction method itself, not merely a new disease target, as the key enabling step, so means-first is the better fit.

## Notes for the codebook
This is a clean means-first case in the "AI applied to medicine" genre: the new capability is not the neural network architecture (borrowed wholesale from computer vision) but a data-pipeline innovation (automated large-scale dataset construction) — worth noting as a variant of means-first distinct from new-instrument or new-theory cases.
